# Tickets Sadi

**Plataforma de boletería social para eventos de gran escala**

Proyecto final: ITI-621 Tecnologías y Sistemas Web III 
Profesor: Jorge Ruiz
Autoras: Diana y Saray Castillo


## Descripción

Plataforma web para vender entradas de conciertos, festivales y partidos. Cada evento tiene un **mural de recuerdos** donde solo los asistentes que hicieron check-in con su código QR pueden publicar fotos. Los usuarios ganan **puntos** por comprar, asistir y por las fotos con más likes, y los canjean por nuevas entradas.
